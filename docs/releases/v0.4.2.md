## 简体中文

- 再次打开当前调试会话的 DevTools 时，优先切回已打开的浏览器标签页。
- FlutterRunlet 会核实热重启是否完成，并在状态栏显示成功结果。无法确认时，会提示原因，并说明如何重新启动调试会话。

## English

- Reopening DevTools for the current debug session switches to its existing browser tab when available.
- FlutterRunlet verifies whether a hot restart completed and shows success in the status bar. If it cannot confirm the restart, it explains why and how to restart the debug session.
