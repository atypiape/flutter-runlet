## 简体中文

- Flutter SDK 来源默认选「自动」。应用启动后即可从 PATH 查找独立安装的 Flutter SDK，即使尚未打开项目，或从 Finder 启动时 Flutter 仅配置在登录 shell 的 PATH 中。设置显示实际 SDK 根目录，调试使用同一 SDK。
- 修复关闭「优先使用项目 FVM」后，缺失的 FVM 缓存链接仍会阻止使用独立 SDK 的问题。现在可使用手动指定的 SDK 或自动发现的 SDK。

## English

- Flutter SDK selection defaults to Auto. FlutterRunlet discovers standalone SDK installations at startup, even before you open a project or when only your login shell's PATH contains Flutter. Settings show the resolved SDK directory, and debugging uses that same SDK.
- Fixed a missing FVM cache link blocking standalone SDKs after Prefer Project FVM was turned off. You can use either a manually selected SDK or an automatically discovered one.
