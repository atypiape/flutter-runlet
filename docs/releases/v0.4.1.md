## 简体中文

- 如果新版的 GitHub 发布尚未锁定，更新提示会引导你前往发布页手动下载安装，并高亮「查看发布页」。

### 手动安装

下载 Universal DMG，退出 FlutterRunlet，然后打开 DMG，将新版拖入「应用程序」并替换旧版。

## English

- When a new version’s GitHub release is not locked, the update message directs you to download and install it manually and highlights “View Release.”

### Manual installation

Download the Universal DMG and quit FlutterRunlet. Open the DMG, drag the new app into Applications, and replace the previous version.
