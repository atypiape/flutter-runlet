## 简体中文

- 支持在 macOS 桌面设备上启动 Flutter 调试。选择离线 iOS 模拟器或 Android AVD 时可自动启动设备，启动 iOS 调试时会显示模拟器窗口。
- 首次打开时，主窗口会提示从文件夹按钮添加 Flutter 项目。打开项目后会默认选中启动配置和设备，设备列表会显示初次刷新状态。
- 调试运行中再次点击「运行」，可以确认后结束当前会话，恢复项目环境，再用原启动配置和设备重新启动。
- 主窗口显示当前调试状态和启动进度。运行日志区分启动与诊断消息的颜色，并随窗口宽度自动换行。

## English

- Debug Flutter apps on macOS desktop. Selecting an offline iOS simulator or Android AVD can start it automatically, and the Simulator window opens when iOS debugging starts.
- On first launch, the main window points to the folder button for opening a Flutter project. Opening a project selects a default launch configuration and device, and the device list shows its initial refresh.
- Select Run during an active debug session to confirm a restart. FlutterRunlet ends the session, restores the project environment, and starts again with the same launch configuration and device.
- The main window shows the current debug status and startup progress. Run logs distinguish startup and diagnostic messages with color and wrap to the window width.
