## 简体中文

- 热重启会等待 Flutter 视图切换到新的 Dart isolate，避免应用已重启却提示「热重启未完成」。
- Inspector 操作反馈显示在主窗口和菜单栏的状态栏。配置变更等提示显示在菜单栏面板底部。
- Flutter 正在启动时，若已有验证过的 SDK，仍可在 Flutter 设置中检查环境。

## English

- Hot restart waits for the Flutter views to switch to new Dart isolates, avoiding an incomplete warning after a successful restart.
- Inspector feedback appears in the status area of the main window and menu bar. Configuration change notices and other messages appear at the bottom of the menu bar panel.
- You can check the Flutter environment from Settings while Flutter is starting if an SDK has already been verified.
