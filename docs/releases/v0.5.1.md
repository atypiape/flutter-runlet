## 简体中文

- 热重启会等待 Flutter 视图切换到新的 Dart isolate，避免应用已重启却提示「热重启未完成」。
- Inspector 操作反馈显示在主窗口和菜单栏的状态栏。菜单栏面板内的提示使用统一样式。
- Flutter SDK 检查期间显示启动进度，Flutter 设置和「运行」按钮会随检查状态更新。

## English

- Hot restart waits for the Flutter views to switch to new Dart isolates, avoiding an incomplete warning after a successful restart.
- Inspector feedback appears in the status area of the main window and menu bar. Messages in the menu bar panel use consistent styling.
- Flutter SDK checks show startup progress and update Flutter settings and the Run button as the checks proceed.
