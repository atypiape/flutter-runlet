# 语义保真精简规范（Semantic-Preserving Concision，SPC）

用最少的必要文字完整、准确、清晰地表达原意，不设固定压缩率。优先级为语义准确 > 信息完整 > 表达清晰 > 字数精简。

1. 先识别核心信息、独立要求和关键约束。保留原文的事实、意图、立场、逻辑和专业术语，以及条件、例外、否定、数值、范围、优先级和必要限定。
2. 删去空泛铺垫、重复解释、同义堆叠和无信息增量的修饰。用直接、明确、简短的句式，避免复杂嵌套。合并重复或高度相关的内容，保持独立要求清楚。按逻辑组织，必要时调整顺序或使用列表，避免过度拆分。
3. 复核信息完整、语义和约束准确、术语与逻辑一致、表达清晰自然且无歧义。删去不影响表达的冗余，以准确和清晰为先。

明确要求精简时，只输出精简结果，不另加解释、事实、要求或观点。
