# FlutterRunlet · 界面与交互规格 v0.1

状态：**G0 最终人工视觉验收已通过**。主要窗口、面板和状态均提供简体中文与英文、深色与浅色画板。应用默认跟随系统语言，项目名、配置名、设备名和 CLI 日志保留原文。[Figma 原型与播放入口](FIGMA-HANDOFF.md#最终原型与播放入口)

## 1. 主窗口

采用 G0.2 的 **640 × 580 pt 默认窗口外框**，无侧栏。正文 13 pt，日志 12 pt，水平边距各 20 pt。工具栏按 52 pt 参考高度绘制，实际内容尺寸随系统标题栏确定。

| 区域 | 布局 | 交互/要求 |
|---|---|---|
| 标题栏 | App 名、打开项目、设置齿轮、关于 `ⓘ` | 打开设置/关于原生窗口；不要复制顶层导航 |
| 项目 | 当前项目路径/名称，选择、打开项目 | 只显示 Flutter 工程，校验 `pubspec.yaml` |
| 配置与设备 | 双列，刷新在设备列 | 配置读取 `.vscode/launch.json`，设备由 CLI 检测。不可用配置显示原因，禁止执行；执行层复验有效性 |
| 运行控制 | Run / Stop / Hot Reload / Hot Restart 同一行 | Run 使用系统强调色。运行中 Run 禁用；根据会话决定其他操作的可用性 |
| 调试会话 | 运行状态、配置、设备、VM 连接状态 | 放置「打开 DevTools」「打开 Inspector」，无服务时禁用/解释原因 |
| 运行日志 | 默认展开，支持折叠、清空、复制 | 保留 CLI 原文。横纵滚动，随窗口高度扩展。清空后折叠、展开时旧日志保持清空 |
| 底部 | 简短项目状态 | Flutter/Dart 版本仅在 Flutter 设置展示 |

### 重点原型状态

- **Empty**：尚未打开项目；明确的「打开项目」动作，其他控件合适禁用。
- **Ready**：项目/配置/设备有效；Run 可用，Stop/Reload/Restart/DevTools 不可用。
- **Starting**：执行前置任务或 Flutter 启动；显示阶段与进度，防止重复 Run。
- **Waiting for VM Service**：仍可停止；Hot Reload、Hot Restart、DevTools 和 Inspector 暂不可用。
- **Running**：Run 不可用，Stop/Reload/Restart 可用（仅有效 Debug 会话）；DevTools/Inspector 连接到本次会话。
- **Stopping / Restoring**：Stop 受控；标注正在执行后置任务，避免将进程结束误认为任务完成。
- **Error / Recovery Needed**：覆盖前置任务失败、配置无效、无设备、prod 恢复失败、重试及恢复成功。prod 恢复失败时提示和重试入口固定在日志之外，折叠日志后仍可见。

## 2. 菜单栏图标与弹出面板

采用 G0.1 验收方向，**404 pt 宽**，高度随状态，容器以系统 `MenuBarExtra(.window)` 为准。

建议自上而下：

1. App 名/图标、简短状态（就绪/运行中/错误）。
2. 当前项目与配置、设备（可切换，但运行中禁止不安全切换；复杂项目管理交给主窗口）。
3. 与主窗口**同一会话**的运行控制（根据状态显示 Run/Stop，以及 Reload/Restart）。
4. 打开 DevTools / Inspector（未连接时禁用）；可有最多 2–3 行简短的最新日志或省略，不在面板做完整控制台。
5. 打开主窗口、设置、退出。

行为：单击菜单栏图标展开原生 popover，再次点击或点击外部关闭；主窗口关闭不应自动结束 Flutter 会话（退出 App 时另行确认并执行清理）。不要出现两个独立的会话控制器。

## 3. 设置窗口：通用

设置窗口为 **640 × 520 pt**，左侧依次为「通用」「Flutter」「DevTools」「关于」。侧栏贯穿窗口左侧，右侧顶部显示当前页名称，下方为可滚动表单。语言、外观、Flutter SDK 来源、DevTools 来源和源码编辑器复用一种下拉菜单。SDK 路径右对齐。更换 SDK、检查环境与更新共用强调按钮，统一高度和内边距。

| 项目 | 控件/说明 |
|---|---|
| 语言 | `跟随系统`（默认） / `简体中文` / `English`，切换后整应用统一语言 |
| 应用外观 | `跟随系统` / `浅色` / `深色`（默认），立即应用并记住偏好 |
| 登录时自动启动 | 开关，默认关闭 |
| 启动后显示主窗口 | 开关，默认开启。检测到待恢复记录时仍显示主窗口，恢复由用户触发 |
| 记住最近打开的项目 | 开关，默认开启 |

Flutter SDK 路径、Flutter/Dart 版本、FVM 和环境检测均在 Flutter 设置展示。DevTools 与 Inspector 通过当前会话的按钮手动打开。

## 4. 设置窗口：Flutter

| 分组 | 内容 | 行为 |
|---|---|---|
| Flutter SDK | SDK 来源（自动/手动）、生效来源、版本与状态、SDK 路径 | 选择模式和实际来源分行；手动路径无效时明确报错，已保存的手动路径未生效时单独显示 |
| FVM | 优先使用项目 FVM、检测状态、项目实际 Flutter 版本 | 有效项目 pin 使用对应 SDK，显示与运行一致 |
| 环境检测 | 「检查环境」、Flutter/Xcode/Android Toolchain 简要结果，「查看完整输出」 | 实际运行 `flutter doctor`；加载/失败/无工具时有状态 |

SDK 的解析/失败规则以 [技术设计](../02-TECHNICAL.md#5-flutter-sdk--fvm--设备) 为准；不支持 SDK 下载、升级或 channel 切换。

## 4.1 设置窗口：DevTools

- 「DevTools」分组显示来源、版本和源码编辑器。来源可选择 Flutter 自带或独立 Dart SDK，编辑器默认 VS Code，可选 Cursor 或 Zed。
- 「Dart SDK」分组在配置了独立路径或存在路径错误时显示。路径独占一行，显示在右侧并可复制。分组标题旁的「更换…」打开目录选择器。

## 5. 关于 FlutterRunlet

采用约 **440 × 480 pt** 的独立窗口，沿用已确认的品牌标志。显示应用名、描述、实际版本与构建号、上游归属及版权。项目主页、README 和项目许可证链接由默认浏览器打开。G3 已验证打开目标，匿名访问在公开发布时复验。[G3 验收记录](../../.planning/milestones/v0.1-phases/05-stability-recovery-release/05-G3-ACCEPTANCE.md)

## 6. 语言与视觉校验

- 切换中文后，所有工具栏标题/标签/设置/菜单栏可见文案仅为中文；切换英文同理。
- 项目名、配置名、设备名、技术名称（Flutter、DevTools、Inspector、FVM）及原始命令和日志保留原文。语言选项可单独显示语言自称，如「简体中文」或「English」。
- 深色、浅色使用相同布局、组件和状态关系，按生效的应用外观切换语义色。
- macOS 菜单栏单色图标在 Light/Dark 主题下清晰，Dock App 图标没有外围多余透明/黑色方框。
- 项目、配置和设备名称较长时单行尾部省略。通过悬停或独立入口查看全名，锁定状态仍可查看。会话信息和错误文案可以换行。

## 7. 可访问性与键盘

- 保留控件的 VoiceOver 可访问名称，图标按钮提供 tooltip。
- 主窗口、设置窗口和系统菜单栏面板停用 Tab／Shift-Tab 控件切换及蓝色焦点框。独立关于窗口和系统目录选择器保留原生键盘行为。
- Disabled 状态不只靠变浅的颜色，也要在快捷键行为上禁用。
- 菜单栏和主窗口状态一致；打开 DevTools 的外链按钮无空链接。
- 日志复制不应包含 UI 机密外泄；VM Service 原始 URL 的展示及持久化应受控。
