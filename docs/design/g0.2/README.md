640 × 580 pt 是**窗口外框**。工具栏沿用 G0.1 的 52 pt 参考高度，对应 640 × 528 pt 的内容布局区域。两侧各留 20 pt，主内容可用宽度为 600 pt。正文和按钮文字为 13 pt，日志为 12 pt 等宽字体。调试按钮沿用 G0.1 的 26 pt 设计高度。

常用项目、配置和设备都能完整显示。双列宽度为 344 和 240 pt，设备列包含刷新按钮。中英文四个调试按钮保持同一行，英文一行含间距占 384 pt。Hot Reload 和 Hot Restart 分别为 105 和 111 pt，当前文案均完整显示。

英文压力样例的项目名、启动配置和会话内重复的配置名采用单行尾部省略。项目和配置旁各有独立的全名查看入口，运行时选择器锁定也能使用。全名叠层里的长项目名换为两行。长名称状态下，VM Service 状态移到下一行，与 DevTools、Inspector 同行。

运行日志默认展开，沿用原始 CLI 文本和样式。Figma 日志区域设为横向及纵向滚动，并保留折叠和清空连线。复制用反馈叠层演示。prod 恢复失败时，正文按句子分两行，重试入口和三行原始日志同时可见。警告位于日志之外，折叠日志时仍然可见。重试链接接回原 G0 的恢复重试状态。

本轮通过 Figma 导出核对四个状态，并检查画板尺寸、控件宽高、日志文本和原型连线。640 pt 下未见核心控件拥挤或重叠。与 760 pt 相比，主要取舍是长值显示字符更少，恢复失败时日志视区变矮。请在人工验收时确认这两项取舍是否符合使用习惯。原 760 pt 源画板及 G0.1 页面结构已复核。
