## 实现视觉约定

- 主窗默认外框 **640 × 580 pt**，无侧栏。52 pt 是标题栏及工具栏参考高度，画板内容区域为 640 × 528 pt。两侧各留 20 pt，正文 13 pt，日志 12 pt。配置与设备双列，四个调试按钮保持同排。
- SwiftUI 优先，AppKit 按需补充。采用原生窗口和控件，Run 使用系统强调色。会话、日志和恢复提示保留应用专属布局。原型日志默认展开，支持横纵滚动、折叠、清空和复制。当前实现自动换行，仅支持纵向滚动，并随窗口高度扩展。
- 两种外观共用 `Runlet G0.1 / Appearance` 的语义色模式和 `Runlet G0.1 / Layout` 的度量变量。Figma 复用 macOS 27 UI Kit 的窗口控件、设置选择器和开关。菜单栏宽 **404 pt**，设置外框 **672 × 520 pt** 且保留左导航，关于外框约 **440 × 480 pt**。
- 项目、配置和设备名称原样保留，超长值单行省略。运行中仍可从字段外层查看完整值。会话可将 VM Service 状态移到下一行。prod 恢复失败的警告和重试入口位于日志外。
- 应用默认跟随系统语言和外观。Figma 用两个外观页和两种系统语言入口分别演示，所有 UI 文案按当前语言显示。Flutter 等技术名称、用户项目名称和 CLI 原文不翻译。

## 设计验证记录

逐帧比对了历史 G0 的 196 张画板与同步后的状态关系，包括阶段计时、条件跳转和原始 CLI 日志。复核了 640 pt 尺寸、英文调试按钮宽度、13/12 pt 字号、两套设置和 404 pt 面板；抽查了深浅色的运行、恢复失败和设置渲染。原型播放验证了中文 prod 启动、日志展开/折叠/清空、菜单栏停止、恢复失败、折叠日志后保留警告、重试成功，以及切换英文后恢复同一会话状态。浅色英文播放从就绪启动并到达运行中。

Figma 的设备、任务、日志复制和浏览器操作使用演示反馈。原型常规运行流程清空后再折叠、展开会回到带示例日志的画板。恢复失败画板的日志组件已经演示保留清空状态。

### 原生控件实测要点

G0 在 macOS 26.7.1、Apple Silicon、macOS SDK 27.0 上运行独立 SwiftUI 实验，核对了以下行为。最终部署目标与运行验收范围见下表。

- 原生窗口控制按钮和工具栏随窗口激活状态变化。Run 使用系统强调色，运行中禁用 Run、启用 Stop。
- 菜单样式 Picker 的单项加 `.disabled()` 后曾仍可选中。不可用配置须可见并说明原因，执行层须复验。实验中原生 Menu 的禁用命令无法触发。
- 普通锚定 Popover 可用 Escape 或点外部关闭。G0 实验未核实关闭后焦点是否返回锚点。
- `MenuBarExtra(.window)` 与主窗共享操作状态。实测点图标或面板外可关闭，面板外观跟随系统。Escape 关闭未确认为 v0.1 要求。
