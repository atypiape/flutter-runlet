# FlutterRunlet v0.1 · G0.1 视觉验收

G0.1 画板入口保存在本地私有交接资料中。[原生控件实测要点](../FIGMA-HANDOFF.md#原生控件实测要点)已纳入最终交接。

| 对比稿 | Figma 画板 |
| --- | --- |
| 主窗口 A / B · 中文运行中 | 760 / 800 pt 并排对照 |
| 中文菜单栏面板 | 404 pt |
| 中文设置 · 通用 | 左侧导航 |
| 中文设置 · Flutter | 左侧导航 |
| 组件与适配 | 英文长名称、恢复、不可用配置、深浅色 |

两张主窗都以**窗口外框**计量。760 × 580 pt 和 800 × 580 pt 均含 52 pt 标题栏及工具栏参考高度，对应 528 pt 内容布局高度。52 pt 来自 macOS 26.7.1 实机，系统会按实际工具栏样式决定高度。SwiftUI 内容尺寸与窗口外框尺寸在验收时分别测量。

主窗从 G0 的 900 × 650 pt 收紧，继续按项目、配置和设备、运行控制、会话、日志排列。设置和关于缩成图标，四个调试动作保持同一行。正文与操作标签采用 13 pt，日志与辅助文字采用 12 pt。会话用浅边界、独立状态标签和两个浏览器入口区分，日志保持默认展开。菜单栏 404 pt 宽，面板内容高 300 pt，显示和主窗口相同的运行状态。设置两页使用 672 × 520 pt 外框与 142 pt 侧栏。开关取值和版本占位仅用于画板示例。

| 实现归属 | 涉及控件 |
| --- | --- |
| 系统原生 | 窗口按钮、标题栏和 Toolbar，普通按钮与图标按钮，配置和设备选择控件，设置表单与开关，菜单栏容器 `MenuBarExtra(.window)` |
| SwiftUI 样式和布局 | Run 用系统 Accent Color，运行中禁用。图标、标题、控件间距及长名称省略由布局适配。配置菜单的当前项有选中标记，不可用项展示原因。执行前再次校验有效性 |
| 应用自定义 | 调试操作分组、会话摘要、可折叠日志和阻塞恢复提示。菜单栏壳内复用同一会话规则。Apple 通用组件没有这些产品语义 |

G0.1 页面中有独立的深浅外观、间距及圆角变量。窗口控制按钮、设置的 Pop-Up 与开关保留 Apple macOS 27 UI Kit 实例。主窗和菜单栏内的按钮及锁定字段是按 SwiftUI 实测制作的可编辑设计示意。配置菜单需要解释禁用原因，单独展示了可用项、禁用项和原因的排布。浅色覆盖同一组颜色变量，系统实际 Accent 和材质在实现时随系统外观。

两种宽度的中文主窗和英文核心布局均通过 Figma 画面检查。英文四个调试按钮完整显示，最紧的是 Hot Reload，当前文案约剩 3 pt 的宽度余量。760 / 800 pt 画板的启动配置文本区分别约 366 / 389 pt。压力样例中的长项目名和配置名在两种宽度下均单行省略。正式界面的完整名称查看方式需要覆盖禁用状态，建议从字段外层提供。760 pt 恢复切片将提示和「重试恢复」放在日志上方，日志折叠时仍可见。

两张主窗均可打开设置。设置导航从主窗叠层切换，菜单栏面板可打开主窗及设置。日志示意支持折叠、展开和清空，复制反馈仅演示提示。完整会话状态流、任务与恢复跳转继续使用原 G0 流程。英文检查限于主窗核心区域，英文设置和菜单栏仍待排版验证。暂定最低版本 macOS 15 的原生材质、控件尺寸和焦点行为仍待实机验证。

人工验收请确认两项。首选 760 pt 或 800 pt 外框宽度，以及当前深色背景、会话面板和日志层次是否可作为后续统一方向。当前对比中 760 pt 可完整承载核心操作，800 pt 的优势是长值及日志多出横向空间。
