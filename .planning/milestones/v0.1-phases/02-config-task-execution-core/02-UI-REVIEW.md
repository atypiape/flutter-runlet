## 优先处理

1. **复验菜单栏会话联动。** 使用最终 Debug 构建在运行中关闭主窗，从菜单栏确认 Stop 可用并执行。复核恢复失败后仍能从面板打开主窗，以及菜单栏退出是否走同一确认。
2. **让锁定的配置可查看完整名称。** 在选中值上提供完整名称的悬停提示或独立可访问入口，避免长名称在运行中被截断后无法辨识。
3. **为恢复失败增加系统警示语义。** 在保留标题和重试动作的基础上，按系统外观使用警示图标或语义色。

## 详细发现

### 文案 · 3/4

- **WARNING** Profile 复验中，运行按钮已禁用并显示「仅支持 Debug 模式」，会话标题仍是「就绪」。重读失败也可能并列显示「就绪」和「配置已过期」。用可观察的可用状态区分正常就绪与配置阻断。 [会话状态呈现](../../../../FlutterRunlet/MainWindowView.swift#L119)
- 「重试恢复」和「打开待恢复项目」区分了执行恢复与打开项目，符合 D-08。项目名称、配置名称、原任务标签和原始任务输出保留原文。 [恢复入口](../../../../FlutterRunlet/MainWindowView.swift#L127)

### 视觉层级 · 3/4

- **WARNING** 恢复截图中，失败标题、退出原因、路径和重试在原生会话组内。标题可辨识，层级与普通会话状态相同，长路径又会占两行。可将风险标题与重试保持邻近，并用系统警示符号区分。 [会话布局](../../../../FlutterRunlet/MainWindowView.swift#L105)
- 原生目录选择面板、工具栏图标名称、四项同排控制及日志折叠入口都可在主窗的可访问性树定位。 [窗口操作](../../../../FlutterRunlet/MainWindowView.swift#L57)

### 色彩 · 2/4

- **WARNING** Run 采用原生突出按钮，背景和分隔使用系统色。恢复标题沿用主文本，原因及路径使用次级文本，源码没有独立的失败语义色。深色截图中禁用 Run 仍保有蓝色填充，实际禁用由可访问性树与执行门槛确认。浅色与增加对比度未实测。 [状态和按钮](../../../../FlutterRunlet/MainWindowView.swift#L119)

### 排版 · 3/4

- **WARNING** 主窗 13 pt 正文、12 pt 等宽日志符合规格。项目和设备标签可通过帮助提示查看全名，实际配置 `Picker` 没有对应帮助提示。锁定状态下长配置名的完整可访问方式待复验。恢复路径为正文样式并与任务标签共用两行，长路径可能挤压标签。 [配置选择](../../../../FlutterRunlet/MainWindowView.swift#L17) · [日志样式](../../../../FlutterRunlet/MainWindowView.swift#L150)

### 间距 · 3/4

- **WARNING** 主窗保留 640 × 580 默认尺寸、20 pt 横向边距，面板宽度为 404 pt。主窗会话区可同时显示两份错误、长路径和恢复动作，展开日志仍保留 96 pt 最小高度。480 × 400 最小窗口下的组合布局尚无原生取证。 [主窗尺寸](../../../../FlutterRunlet/FlutterRunletApp.swift#L29) · [面板尺寸](../../../../FlutterRunlet/MenuBarPanelView.swift#L55)

### 交互 · 3/4

- **WARNING** 两处传入同一会话并复用 Run/Stop 控件。菜单栏只有存在恢复或恢复存储错误时才显示原因，配置无效或当前构建无调试适配器时，面板只显示禁用按钮和简短状态。主窗已有诊断，可在面板复验简短原因及主窗入口的可发现性。 [共享会话接线](../../../../FlutterRunlet/FlutterRunletApp.swift#L29) · [面板错误条件](../../../../FlutterRunlet/MenuBarPanelView.swift#L32)
- 已观察主窗收起日志后可重试、关闭主窗后会话继续、系统退出等待恢复以及风险未解除时取消退出。菜单栏启停、面板重开主窗、菜单栏退出与键盘焦点仍待实机确认。完整双语、Flutter 设备、VM Service 和热操作依路线图在后续阶段验收。 [原生验收记录](02-P2-ACCEPTANCE.md)
