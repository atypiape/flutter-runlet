# Phase 03 · Flutter 调试闭环 UI 契约

## 最终原型对照

从本地私有交接入口核对最终深色、浅色页面的主窗、菜单栏、设置、选择器与提示、prod 恢复和 640 pt 长名称分组，并抽查深色热重载、日志复制和 DevTools 反馈画板。分组与本阶段的对应关系见[公开交接清单](../../../../docs/design/FIGMA-HANDOFF.md#画板清单)。

- 「选择器与提示」中的项目文件夹和 SDK 路径选择沿用原生选择器；取消选择保留现项目、SDK 和日志。640 pt 长名称画板对应 E1、E2 和 E8，验收时使用长项目名、配置名和设备名，检查锁定后仍能查全名。
- 「已热重载」「已热重启」「已复制运行日志」对应 E10。只在对应操作实际成功后给出可关闭的原生反馈。关闭反馈不改变会话、选择或日志。复制反馈采用 D-16 的令牌遮罩规则。
- DevTools 和 Inspector 反馈画板为浏览器动作演示；正式行为按当前会话打开系统默认浏览器。常规运行画板清空日志后再折叠、展开可能回到带示例日志的画板；正式行为按 A30 保持已清空并继续追加。通用设置、完整语言切换、环境检测和关于窗口沿用现有阶段分工。

## 设备、SDK 与浏览器

- **设备（D-01–D-04）**：设备选择器使用实际扫描结果，原样显示名称。首次打开且无显式 `deviceId`、无本次 App 打开期间的项目选择时，零台显示引导、一台自动选中、多台留空。手动刷新和启动前刷新后，原设备离线则保留选择并标为离线；同一设备重连后重新评估运行条件。显式设备冲突时保留现选择，显示配置目标，用户通过设备菜单改选目标，期间禁用运行。按项目记忆只在本次 App 打开期间有效。刷新中显示进度；扫描失败显示原因并允许刷新重试。iOS 模拟器未启动且可启动时，使用现有设备区域的「启动 iOS 模拟器」入口；启动中显示进度，成功后刷新设备，失败说明原因和下一步。任何自动选择或刷新都不自动运行。
- **SDK（D-05–D-08）**：按技术契约解析项目 FVM、手动 SDK 与系统路径，显示与执行使用同一结果。项目要求的 FVM SDK 缺失、已生效的手动路径无效或没有可用 SDK 时，显示具体原因，禁用运行并提供「打开 Flutter 设置」。App 重新激活时重检此前无效的 SDK；检查通过且其余条件满足后只恢复按钮。有效设置下，新手动路径先验证，失败在设置中报错并保留原值，通过才应用。会话期间显示本次实际使用的 SDK 和版本，SDK 修改控件锁定，直到会话确认停止且完成适用的恢复。
- **浏览器（RUN-04）**：仅在当前 Debug 会话的 VM Service 已连接并可生成有效地址时，浏览器入口才可用；默认浏览器打开当前会话。优先使用 Flutter 提供的当前 DevTools URL。Inspector 直达须经目标版本实测；不支持可靠直达时，打开已连接的 DevTools 并提示用户进入 Inspector。打开失败给出原因与重试路径。连接中断、停止、退出或会话变更后不复用旧链接；重连后以已验证的连接为准，停止后重新运行必须重新绑定新会话。完整敏感 URL 不出现在 UI 或剪贴板日志中，也不默认持久化。

## 会话操作矩阵

主窗和菜单栏共用以下状态与操作门槛。设置中的会话 SDK 使用同一来源；两个入口的重复请求不得绕过锁或启动第二个 Flutter 进程。运行前重新校验项目、配置、SDK 和设备；配置或引用任务已变化且新值有效时，更新界面，等用户再次点「运行」后才启动。

| 状态与转移 | 运行 | 停止 | 热重载／热重启 | 两个浏览器入口 |
| --- | --- | --- | --- | --- |
| 无项目、配置无效或过期、SDK 或设备未就绪 | 禁用，显示原因与下一步 | 禁用 | 禁用 | 禁用 |
| 就绪：启动条件满足且无待恢复记录 | 可用 | 禁用 | 禁用 | 禁用 |
| 启动检查 | 禁用重复请求 | 沿用 Phase 02，尚无可停止的操作时禁用 | 禁用 | 禁用 |
| 正在运行前置任务／正在启动 Flutter | 禁用 | 可停止时启用，沿用 Phase 02 受管停止 | 禁用 | 禁用 |
| 等待 VM Service | 禁用 | 可用 | 禁用 | 禁用 |
| 等待较久：进程仍在，进程启动满 **60 秒**且未连接；前置任务时间不计（D-09、D-10） | 禁用，继续等待 | 可用 | 禁用 | 禁用 |
| 运行中：当前 Debug 会话已连接 | 禁用 | 可用 | 可用，作用于当前进程 | 仅有当前有效连接时可用 |
| VM Service 连接中断：进程和设备仍正常，尝试重连本次会话（D-11） | 禁用 | 可用 | 禁用，重连后恢复 | 禁用，重连后按当前地址恢复 |
| 确认设备断开（D-12） | 禁用，显示断开原因并主动停止 | 主动停止后禁用重复停止 | 禁用 | 禁用 |
| 停止中、进程退出确认中、执行后置恢复 | 禁用，分别显示停止和恢复阶段 | 禁用 | 禁用 | 禁用 |
| 前置失败、启动失败、进程异常退出或恢复失败 | 不再显示运行中；项目锁、退出确认、后置恢复或持久风险阻塞时禁用。解决原因、完成适用恢复并满足启动条件后可用 | 禁用重复请求 | 禁用 | 禁用 |

确认 Flutter 进程退出后才执行适用的原后置任务。进程退出未确认时不得执行恢复、解锁、重试启动或报告安全结束。恢复失败时保留项目、原任务和失败原因，显示「重试恢复」或「打开待恢复项目」；入口留在主窗日志外，按 Phase 02 规则处理。恢复成功后清除阻塞并重新评估就绪条件。进程异常退出或设备断开原因在恢复后仍可查看；主窗关闭时从菜单栏可看到当前状态与阻断。

## 运行日志

- 保留流式 CLI 输出；默认跟随底部，用户向上阅读时保持位置，滚回底部才恢复跟随（D-15）。长行可横向滚动，多行可纵向滚动。保持可选中文本，支持复制和清空。
- 日志内容与折叠状态独立。清空后折叠、展开或重开主窗不会还原旧日志，后续输出正常追加。清空只影响 App 中的日志，不停止会话或清除恢复记录。
- 停止和适用的恢复结束后仍保留本轮日志。下一轮真正通过启动检查并开始执行时清空；仅复验、配置变更提示或启动被阻断时保留。成功切换到另一项目时清空；取消或切换失败时保留（D-13、D-14）。
- 展示、选区复制和复制日志均保留 VM Service/DevTools 地址与端口，但遮住连接令牌；其他 CLI 内容原样保留。浏览器使用当前会话内的有效连接，不从遮罩后的展示文本取地址（D-16）。

## Spacing Scale

| 间距 | 用途 |
| --- | --- |
| **4 pt** | 字段标题和值之间 |
| **8 pt** | 同排按钮、会话内容与日志区内间隔 |
| **16 pt** | 主窗区块、配置设备双列间隔与菜单栏内边距 |
| **24 pt** | 设置内容内边距 |

沿用 G1 已验收的 **12 pt** 菜单栏组间距、**20 pt** 主窗水平边距，作为现有布局例外。窗口外框、设置导航宽 142 pt、标题栏 52 pt 与按钮高度 26 pt 的画板参考均不是间距 token；原生控件实际高度由系统决定。

## Color

| 角色 | 取值及范围 |
| --- | --- |
| 主表面（60% 层级） | 系统窗口背景，占主要视觉面积 |
| 次表面（30% 层级） | 原生弹出面板、设置导航及日志背景，区分辅助区域 |
| 强调（10% 层级） | 仅为可用的「运行」按钮使用系统强调色。系统选中与键盘焦点反馈维持原生行为 |
| 文本与告警 | 原生主／次文本与告警语义；状态点为辅助，错误和恢复失败以文字说明。不新增破坏性色按钮，停止和清空日志保留原生按钮样式 |

60／30／10 用于主次和强调的层级判断，无须在原生窗口按像素配色。随系统深浅外观切换；两种外观下保持相同布局、状态和可读性。

## Copywriting Contract

以下为简体中文契约。每个界面只显示当前语言；原样保留用户名称和 CLI 内容（敏感令牌遮罩除外）。「运行」沿用已确认标签和位置，VoiceOver 动作名应明确为「运行当前调试配置」。

| 元素 | 标签／提示与下一步 |
| --- | --- |
| 无项目／无配置 | 「未选择项目」→「打开项目」；「请选择配置」→从配置菜单选择。配置无效或过期时显示文件与原因，修复后「重读配置」。 |
| 未选择设备／正在刷新 | 「请选择调试设备」；「正在刷新设备」。设备列使用「刷新设备」。 |
| 无可用设备／扫描失败 | 「未发现可用调试设备。请连接设备或启动模拟器，再刷新设备。」；「无法刷新设备：{原因}。请检查后刷新设备。」 |
| 设备离线／配置冲突 | 「{设备}已离线。请重新连接该设备。」配置未指定设备时也可在设备菜单另选；「此配置要求设备 {目标设备}。请在设备菜单选中该设备。」 |
| 模拟器启动 | 「启动 iOS 模拟器」「正在启动 iOS 模拟器」；失败：「无法启动 iOS 模拟器：{原因}。请检查模拟器后重试。」 |
| SDK 不可用／重检 | 「项目要求的 FVM SDK 不可用：{原因}。请修复项目指定的 SDK。」或「当前 Flutter SDK 不可用：{原因}。请检查 SDK 路径。」→「打开 Flutter 设置」；「正在检查 Flutter SDK」。 |
| SDK 路径编辑／会话锁定 | 「选择 Flutter SDK 路径」；「无法使用所选路径：{原因}。原设置已保留。」；「停止当前会话并完成环境恢复后可修改 SDK 设置。」 |
| 调试操作／状态 | 「运行」「停止」「热重载」「热重启」；「就绪」「正在运行前置任务」「正在启动 Flutter」「运行中」「正在停止」「正在恢复环境」。热操作失败：「{操作}未完成：{原因}。请确认当前调试连接后重试。」 |
| 等待／重连 | 「等待 VM Service 连接」；「等待较久，仍在等待 VM Service。可继续等待或停止。」；「VM Service 连接中断，正在尝试重连。可停止当前会话。」 |
| 设备断开／会话失败 | 「调试设备 {设备} 已断开，正在停止会话。重新连接后可再次运行。」；「{阶段}失败：{原因}。请查看运行日志并检查后重试。」有恢复风险时显示对应恢复路径。 |
| 环境恢复／退出未确认 | 「环境恢复失败：{原因}。」→「重试恢复」或「打开待恢复项目」；「进程退出尚未确认，暂不能启动或恢复。请检查受管进程状态。」 |
| 浏览器 | 「打开 DevTools」「打开 Inspector」；未连接时以会话状态说明。回退：「已打开当前会话的 DevTools，请选择 Inspector。」；失败：「无法打开 {入口}：{原因}。请检查默认浏览器和当前连接后重试。」 |
| 日志 | 「运行日志」「清空日志」「复制日志」；初始为空：「尚无运行日志。启动调试后将在这里显示输出。」；清空后为空：「日志已清空，后续输出将在这里显示。」清空只针对 App 的日志，沿用原型直接清空，不弹确认。 |
| 操作反馈 | 当前会话确认成功后：「已热重载」／「已热重启」，正文「当前调试会话继续运行。」复制成功后：「已复制运行日志」。复制失败：「无法将运行日志写入剪贴板。请再次选择『复制日志』。」复制内容按 D-16 遮罩连接令牌。沿用「关闭」动作。 |
| 停止／退出确认 | 手动「停止」直接进入停止及适用的恢复。退出活跃会话沿用原生确认「停止会话并退出 FlutterRunlet？」／「停止并退出」，取消则保留会话。未确认退出或恢复未解决时保留 Phase 02 阻断提示。 |
