  </action>
  <verify>
    <automated>set -eu; candidate=$(cat .private/phase-05/current-candidate); cd "$candidate"; /usr/bin/shasum -a 256 -c FlutterRunlet.zip.sha256; unpacked=$(mktemp -d "${TMPDIR:-/tmp}/runlet-phase05-unpack.XXXXXX"); trap 'rm -rf -- "$unpacked"' EXIT; /usr/bin/ditto -x -k FlutterRunlet.zip "$unpacked"; for app in FlutterRunlet.app "$unpacked/FlutterRunlet.app"; do test -x "$app/Contents/MacOS/FlutterRunlet"; test -x "$app/Contents/Helpers/FlutterRunletSessionWorker"; /usr/bin/codesign --verify --strict "$app/Contents/Helpers/FlutterRunletSessionWorker"; /usr/bin/codesign --verify --deep --strict "$app"; done; /usr/bin/diff -qr FlutterRunlet.app "$unpacked/FlutterRunlet.app"</automated>

  </verify>
  <done>同一候选可通过 ZIP 传入目标系统，解包后文件、执行位和签名通过并有启动实测证据。</done>
