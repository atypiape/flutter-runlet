# 阶段 06 · 主窗口与菜单栏

**依据** 2026-11-14 已确认的 v0.2 原型、提交 `ee40a61` 的需求及路线图、本轮规划指令。以下记录从现有决定提取。

<domain>
## 阶段范围

交付两处共享操作和各自布局，覆盖项目、下次运行设备、调试、日志与恢复。在本轮只交付已核验的计划供审阅。
</domain>

<decisions>
## 已确认决定

- **D-01:** 两处共享项目、会话、启动配置、下次运行设备及调试操作。所有状态固定显示六项操作并呈现启禁用。遵循语义配色、中英文、系统深浅外观、键盘与辅助功能要求。
- **D-02:** 项目名右侧依次是历史与目录。历史条目可打开或单独移除，最后一条移除后显示空态。继续限制运行与恢复期间切换项目。
- **D-03:** 两处按相同设备名称、类型与在线状态展示列表。会话期间可以改变下次运行设备，当前进程、调试连接和会话信息继续引用启动设备。启动重新校验可用性。
- **D-04:** 菜单栏宽 348 pt，主窗口默认 640 × 520 pt，按两张确认画板布局。两处右上角齿轮打开现有同一设置。
- **D-05:** 恢复失败在主窗原状态区显示错误任务、退出码、运行提示和快速重试。菜单栏使用失败状态标签和快速重试。单点重试只跑原恢复任务。主窗失败时可选配置，运行先恢复再用所选配置启动，重复失败保留风险并阻断启动，恢复中阻止重入。
- **D-06:** 日志工具栏提供复制、清空、展开与折叠，清空后保持空态并继续接收新输出。恢复详情保留独立入口。
- **D-07（2026-11-15 用户确认）:** 接受 macOS 原生目录选择器、标题栏按钮和弹层外框与 Figma 的差异。继续修整应用控制的像素差异，最终 Release 的真实菜单栏逐状态验收通过后方可签核。阶段 07 另行规划，公开发布继续暂缓。
- **D-08（2026-11-15 用户确认）:** 本阶段停做 Tab 焦点和 VoiceOver 专项，移出签核条件。
- **D-09（2026-11-15 用户要求）:** 阶段 06 之后单独移除 FlutterRunlet 的 Tab 焦点功能，解决控件持续显示蓝框的问题。原生复验已看到配置禁用后仍保留蓝框，本阶段继续以当前候选取证。
</decisions>
