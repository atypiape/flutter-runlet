# 阶段 06 · 原生界面复核

## 2026-11-15 · 签核后移除 Tab 焦点

使用修订 Release 的真实主窗口和系统菜单栏面板，在 macOS 深色模式复验。两处按 Tab／Shift-Tab 均不切换控件。打开历史、设备和配置弹层后再关闭，或从系统目录选择器返回，均未观察到残留蓝框。两处从就绪使用 F5 启动真实 Flutter，等待 VM 和运行期间禁用的配置无蓝框，Shift-F5 可停止。设置与系统目录选择器仍可按 Tab 切换原生控件，目录选择器仍可用 Escape 取消。样例恢复到 test，风险为零。截图保存在本机验收目录 `no-tab-focus`。
