# 阶段 06 · 本地联验

## 2026-11-15 · 最终候选补验

使用隔离 Release `f96a8d6`、此前两个样例项目和两个 iOS 模拟器。以下为本轮实机证据，早期候选的证据保留在下方。

- 菜单栏从 A 启动 prod。主窗把下次设备改为 B，两处均显示 B，当前会话仍显示 A。热重载、热重启成功，浏览器呈现 A 会话的 Inspector 组件树。正常停止时 A 上的 Flutter 先退出，随后原后置恢复 test，风险清零。
- B 关机并刷新后，两处保留 B 的名称和类型并禁用运行。菜单栏刷新复连后，两处显示 B 在线。第一次启动 B 时 Flutter 报临时目录异常，随后同一候选复跑，在 B 上看到真实应用输出、VM 连通及正常停止恢复。
- 主窗实际后置失败时显示任务与退出码 1。故障保留时再次运行仍被阻止，退出显示原因。单独重试后环境 test、风险 0。另一轮暂停旧后置时 Flutter 已退出且风险为 1，项目切换、运行和重试入口禁用。放行后先出现 test、风险 0，再执行 dev 前置并创建 B 的 Flutter 进程。
- 独立确认退出回合中，主窗 F5 在恢复中未触发新进程。选择停止并退出后候选继续等待，放行原 test 后置后风险清零、应用退出，期间无 dev 前置和新 Flutter。
- 主窗日志可复制。运行中清空并收起、展开后，只有清空后的计数输出继续追加。
- 菜单栏经原生目录选择打开第二个样例，从两条历史逐条移除至空。主窗复验只剩一条的中间状态、最终空态和仍然打开的项目，重启后历史持久为空。

两处六种状态的双语深浅复验共 48 张。阶段 06 本地联验和视觉复验通过，原始截图和时间线留存本机。见[原生界面复核](06-UI-REVIEW.md)和[本地验收结果](06-UAT.md)。
