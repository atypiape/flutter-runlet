# 阶段 07 · 设置、关于与更新讨论记录

**日期** 2026-11-15

规划依据见 [阶段上下文](07-CONTEXT.md)。用户选择讨论更新交付、检查时机及调试和恢复期间的更新，随后补充安装与重启失败处理。

| 议题 | 讨论过的选择 | 确认结果 |
| --- | --- | --- |
| 更新验收 | App 内安装并重启，或下载后手动替换 | 两份隔离构建之间由 App 安装并重启，核对三处实际版本与构建号 |
| 版本来源 | 仅正式 Release，或也纳入公开预发布版 | 仅正式 Release。用户已公开仓库，并将 `v0.1.1` 改为正式 Release |
| 检查时机 | 仅手动，或首次进入「关于」时自动检查一次 | 仅手动触发，在两处同步 |
| 调试或恢复期间 | 空闲后才开始下载，或先下载再等空闲 | 允许先下载，完成会话和恢复后由用户确认安装 |
| 两处「关于」都已关闭 | 回到「关于」时提示，或空闲后主动弹窗 | 更新包已就绪且允许安装时主动弹窗 |
| 暂缓安装 | 保留本次运行的更新包，或取消并清除 | 选择「稍后」后保留，两处可手动继续，同一次更新无需再次主动弹窗 |
| 下载或校验失败 | 重试、查看发布页，或同时提供两者 | 保留当前版本，同时提供两项操作 |
| 安装失败或新版打不开 | 恢复旧版并尝试打开，或恢复旧版由用户打开 | 恢复旧版并尝试打开，旧版显示原因并提供重试和发布页 |
| 旧版也无法自动打开 | 给出恢复位置和操作，或仅显示结果和原因 | 显示 App 位置，提供「在访达中显示」和「查看发布页」 |

用户确认将以上决定写入阶段上下文。公开 Release 的状态与既有发布说明内容分别记入上下文。
