# FlutterRunlet v0.2 需求

**里程碑** v0.2 界面与调试体验

**设计基线** 2026-11-14 确认的菜单栏、主窗口、设置和关于窗口原型。Figma 编辑与播放入口见本地交接。

**交付范围** 本地实现与验收。公开发布继续暂缓。

## 共用界面

- [ ] **UI-07** 使用已确认原型的语义配色和共用组件。四处界面保持中英文、系统深浅外观、键盘焦点与辅助功能可用。图标按钮提供可读名称。阶段 06 的主窗口和菜单栏部分已签核，四处界面联验归阶段 07。
- [x] **UI-08** 主窗口与菜单栏共用项目、会话、配置和下次运行设备状态。各状态固定显示运行、重载、重启、停止、DevTools 和 Inspector，不可操作时禁用。运行使用绿色三角形，紧邻启动配置下拉框。
- [x] **UI-09** 项目名右侧依次显示历史项目和文件夹按钮。历史列表可切换项目，点某行垃圾桶仅清除该条记录，全部清除后显示空状态。文件夹按钮打开系统目录选择对话框。保留会话与恢复期间的项目切换限制。
- [x] **RUN-07** 两处设备列表使用相同的名称、类型和在线状态，右侧绿点表示在线、红点表示离线，并提供可读状态。运行中允许更新下次启动的设备选择，当前调试会话继续绑定原设备。启动仍需校验设备可用性。

## 菜单栏与主窗口

- [x] **UI-10** 菜单栏按确认的 348 pt 原型实现。项目行下方是等宽的重载、重启、停止按钮，随后依次为运行及启动配置、设备、DevTools 与 Inspector。右上角为状态和无文字设置齿轮，底部提供「主窗口」「退出」。
- [x] **UI-11** 主窗口默认尺寸采用 640 × 520 pt。按原型组织项目入口、配置与调试控件、设备与会话工具、状态区和日志。主窗口和菜单栏右上角齿轮都打开同一套设置。
- [x] **RUN-08** 恢复失败时，主窗口的状态区原位变红，两行分别显示失败任务及退出码，以及「点运行按钮，可尝试恢复并启动」。右侧是青色、透明底的细线双箭头重试图标。菜单栏以状态标签及同款图标提供快速重试。
- [x] **RUN-09** 单点重试只执行原恢复任务。主窗口恢复失败时允许选择启动配置，点击运行先完成前次恢复，再用所选配置启动。恢复再次失败时保留风险标记、显示失败并阻止启动。恢复中禁止重复执行。
- [x] **UI-12** 主窗口日志工具栏提供复制、清空和折叠图标，清空图标与相邻按钮同色。展开显示向下箭头，收起显示向右箭头。清空后折叠、展开不会恢复旧内容，新日志可继续进入。恢复详情可独立于日志查看。

## 设置与关于

- [ ] **UI-13** 设置窗口宽 520 pt，左栏为「通用」「Flutter」「关于」，底部用说明文字的颜色和字号显示实际版本与构建号。开关采用白色滑块，开启时用更新按钮同款蓝色，关闭时用灰色。
- [ ] **UI-14** 「通用」提供语言、登录时自动启动、启动后显示主窗口、记住最近打开的项目。「Flutter」提供 SDK 来源、路径、版本与状态、FVM 优先设置和环境检测及完整输出，保留现有设置行为。
- [ ] **UI-15** 独立关于窗口采用 400 × 412 pt，显示项目标志、实际版本和构建号、「轻量 Flutter 运行与调试工具」、MIT 许可证与 Svame 署名。与设置「关于」页共用品牌、版本、更新和链接组件。两处都使用带图标的「Github」「使用文档」「项目许可证」，并打开各自对应的页面。保留仓库现有许可与归属记录。
- [ ] **UPD-01** 关于页面与窗口共用更新状态。检查以 GitHub 最新正式 Release 为版本来源，检查中显示旋转指示与「检查中...」，无新版显示「已是最新版本」，有新版显示「检测到新版本：vX.Y.Z」及带图标的「更新到 vX.Y.Z」。无法读取发布信息时显示失败或不可用。
- [ ] **UPD-02** 更新过程显示旋转指示与「更新中...」，完成后关于两处与设置侧栏同步显示实际安装版本。Figma 中的 v1.5.0、build 256 和完成反馈均为演示。实现规划须确定私有预发布期间可验证的更新交付方式及失败处理。公开发布、签名、公证与公开可用性复核继续暂缓。
