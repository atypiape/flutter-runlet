# 阶段 06 · 原生界面复核

以[阶段规格](06-UI-SPEC.md)及其已验收原型为基线，核对普通 Release 的实际呈现。主窗为 640 × 520 pt，面板为 348 pt。原始图不入仓库，候选标识及操作记录见[本地联验](06-ACCEPTANCE.md)。

| 维度 | 复核 |
| --- | --- |
| 规格对应 | 两处项目区、配置、设备、热操作、状态、齿轮、日志或底部入口按各自原型排布。 |
| 反馈 | 实际主窗预检、等待 VM、运行及恢复失败，面板等待、运行、失败与就绪可见。面板英文长状态名在胶囊内截断，AX 名称完整；详细失败文字可读。 |
| 层级 | 运行三角、等宽热操作、齿轮及青色恢复入口位置一致。空闲与等待 VM 的禁用语义已在原生窗口核对。 |
| 内容 | 英文历史和设备弹层的语言遗漏已修复并经原生复验；两处可在 AX 中读到图标名称。 |
| 外观 | 已核对两处浅色及部分深色；完整语言与会话状态组合待补。系统已恢复深色。 |
| 交互和辅助 | 菜单栏原生目录对话框的选择、取消均回原入口；主窗及菜单栏齿轮进入同一设置窗口。实际 VoiceOver 朗读、Return 及 Escape 专项见后续 UAT。 |
