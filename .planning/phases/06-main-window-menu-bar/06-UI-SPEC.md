# 阶段 06 · 界面约定

视觉核对入口见 [Figma 交接](../../../docs/design/FIGMA-HANDOFF.md#v02-界面原型)及其指向的本地私有交接。规划时在 Figma 桌面端查看了菜单栏和主窗口的就绪、运行中、正在恢复和恢复失败画板，以及设备、历史项目、目录选择和主窗配置选择示意。复用 [设计系统](../../../docs/design/DESIGN-SYSTEM.md)与 [UI 规格](../../../docs/design/UI-SPEC.md)中仍适用的语义与原生交互。v0.2 需求与新画板覆盖旧布局和尺寸。

| 区域 | 菜单栏 | 主窗口 |
| --- | --- | --- |
| 窗口 | 348 pt 面板 | 640 × 520 pt 默认窗口，保留原生窗口按钮 |
| 顶部 | 品牌，右侧状态与无文字齿轮 | 品牌，右侧状态与无文字齿轮 |
| 项目 | 项目名，右侧历史图标再接文件夹 | 同顺序 |
| 调试 | 等宽重载、重启、停止一行。其下运行和配置一行，设备一行，DevTools 与 Inspector 一行 | 第一行左侧运行和配置，右侧重载、重启、停止。第二行左侧设备，右侧 DevTools 与 Inspector |
| 状态 | 顶部状态标签。恢复失败时标签左侧快速重试 | 控件下方原位状态区。恢复失败时红底、第一行失败任务及退出码、第二行「点运行按钮，可尝试恢复并启动」，右侧快速重试 |
| 底部 | 左「主窗口」，右「退出」 | 状态区下方运行日志。工具栏从左到右为标题、复制、清空、折叠 |

- 运行使用绿色三角形并紧邻配置下拉。两处六个调试操作固定占位。就绪按前置条件启用运行。运行中启用适用的热操作、停止和会话工具，其余操作禁用。VM 尚未就绪时等连接成功再启用热操作和浏览器入口。正在恢复时阻止重复操作。
- 恢复失败画板中仅主窗配置和运行可用于「恢复并启动」。两处快速重试采用相同的青色透明底细线双箭头，具有可读名称。恢复详情独立于日志，继续覆盖风险记录不可用、待打开恢复项目和执行未确认等非退出码场景。仅在真实退出码存在时显示数值。
- 设备列表展示名称、类型、右侧绿点在线／红点离线及可读状态，说明所选设备用于下一次运行。项目历史行包含打开和删除两个可独立操作的目标，删除后最后一条消失时显示空态。目录入口调用系统目录选择器。
- 日志清空图标沿用相邻按钮的颜色。展开图标朝下，收起朝右。恢复详情与日志工具栏无依赖。保留日志可选择、复制、阅读定位及原有容量限制。
- 两处使用同一套状态、调试按钮、设备和项目选择组件或现有数据绑定，布局分别组合。保持系统深浅色和语义对比。中文和英文都验证 348 pt 面板与 640 × 520 pt 默认窗口，包含焦点可达、可读名称、禁用状态、使用键盘取消弹层及返回焦点。标点、任务名和设备名按实际内容显示。
- 设置齿轮进入现有同一窗口。阶段 07 负责设置与关于窗口内部、更新和四处联验。
